# One entry per line: <original text><TAB><translation>. Escapes: \n newline, \t tab, \\ backslash.

# matches a number the game inserted; %d in the translation puts it back.
# A translation may start with {system} or {bitmap} to pick the renderer for the strings it
# appears in (default: [Text] Renderer in DiceFantasy.ini; {bitmap} wins over {system}).
# System font: any text. Bitmap font: plain ASCII is converted to full-width characters;
# . , : ; ' " % have no glyph yet (use … for ...); 六 and 三 are dice icons.
